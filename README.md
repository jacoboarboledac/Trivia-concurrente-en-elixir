# Trivia concurrente en Elixir

Proyecto final de Programación III de la Universidad del Quindío.

## Requisitos
- Elixir 1.14 o superior.
- Erlang/OTP compatible con la versión de Elixir.

## Preparación
Desde la raíz del repositorio, instalar las dependencias:

```bash
mix deps.get
```

## Ejecutar pruebas

```bash
mix test
```

## Estado actual
El repositorio contiene la estructura inicial del proyecto Mix, la dependencia Jason, el módulo de utilidades `Util` y cinco pruebas iniciales para ese módulo. La lógica de la trivia todavía está pendiente.

Consulta [CONTEXTO_PROYECTO.md](CONTEXTO_PROYECTO.md) para conocer los requisitos, la arquitectura prevista y el avance.
